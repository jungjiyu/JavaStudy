			: DTO 의 기본생성자와 getter/setter 가 필수인 이유 >> Reflection API 
				: Reflection API >> 자바에서는 JVM이 실행되면 작성된 자바 코드가 static 영역에 저장된다. Reflection API는 이 정보를 활용하여 구체적인 클래스 타입을 알지 못해도 클래스 이름을 통해 static 영역에서 그 클래스의 정보(메서드, 타입, 변수 등등)에 접근할 수 있게 해준다.
					: @RequestBody 나 JPA 에 Reflection API 가 사용되고, Reflection API 는 생성자와 getter 를 필요로 한다고 한다.
