테이블 join : 두 개의 테이블을 엮어 하나의 결과를 추출할 때 사용
	: https://velog.io/@newdana01/Database-%ED%85%8C%EC%9D%B4%EB%B8%94-%EC%A1%B0%EC%9D%B8-%EC%9D%B4%ED%95%B4%ED%95%98%EA%B8%B0
	: PK 와 FK 관계로 맺어져야됨 ( 일대다 관계 )
	: 쿼리문 tip  >>
		: FROM 바로 뒤의 테이블이 "기준테이블"
		: 테이블조인에 대한 조건은 "on" << 그러니까 어떤 기준으로 테이블 묶을 건지.
		: 데이터필터링에 대한 조건은 "where" << 그러니까 어떤 데이터만 표시할지.
		: 조인할때 등장하는 대부분의 컬럼명은 "." 으로 테이블을 명확히하여 표시함.
			: 쿼리문에 등장하는 두 테이블이 공통으로 가지는 컬럼을 불러오고 싶은 경우, 테이블을 명시하지 않으면 어떤 테이블에서 컬럼을 가져오라는건지 못알아먹는다.

	: 종류
		(1) INNER JOIN 내부 조인: 교집합 데이터를 기준으로 결합하여 조회하는 방법.
			: 조인 관계에 부합되는 레코드"만" 결과로 가지고, 두 테이블 중 어떤 테이블을 기준으로 하든 결과가 같다.
			: 형식
			    : 조회할컬럼목록 의 경우 콤마로 나열
			    : 사실 "FROM 첫테이블, 둘째테이블" == "FROM 첫테이블 JOIN 둘째테이블" == "FROM 첫테이블 INNER JOIN 둘째테이블" 이다. 그러니까 왠만해선 INNER JOIN 취급당한다고 봄 된다.

				SELECT <조회할컬럼목록>
				FROM <첫테이블>
				    INNER JOIN <둘째테이블>
				    ON <조인 조건>
				[WHERE 검색 조건]


		(2) OUTER JOIN 외부 조인: 공통데이터 뿐 아니라 한쪽에만 존재하는 데이터까지도 함께 결합하여 조회하고자 할 때 사용하는 방법
			: 조인 관계에 부합되지 않는 레코드도 어떤 테이블을 기준으로 OUTER JOIN 하느냐따라 남기도 하고, 어떤 테이블을 기준으로 하느냐 따라 결과가 다르게 나오기도 한다.

			: OUTER JOIN의 종류 >> 어느 테이블을 기준으로 삼을 것인가
			    : 기준 테이블의 것은 모두 출력된다.
				1. LEFT OUTER JOIN : 첫번째 테이블(FROM키워드 뒤)을 기준으로 한다. >> 일단 첫번쨰 테이블의 행은 모두 출력된다. 그리고 두번쨰 테이블에선 조인관계를 만족하는 부분만 출력한다. 매치되는 데이터가 없는 행은 null 로 표시된다. 
				2. RIGHT OUTER JOIN :  두번째 테이블(JOIN 키워드 뒤)을 기준으로 한다. >> 일단 두번째 테이블의 행은 모두 출력된다. 그리고 첫번째 태이블에선 조인관계를 만족하는 부분만 출력한다. 매치되는 데이터가 없는 행은 null 로 표시된다. 

				3. FULL OUTER JOIN : 왼 오 테이블의 모든 값이 출력된다 << 성능상 거의 사용하지 않는다.

SELECT <열 목록>
FROM <첫 번째 테이블(LEFT 테이블)>
    <LEFT | RIGHT | FULL> OUTER JOIN <두 번째 테이블(RIGHT 테이블)>
     ON <조인 조건>
[WHERE 검색 조건]

		(3) CROSS JOIN 상호 조인 : 한쪽 테이블의 모든 행과 다른 테이블의 모든 행을 조인하는 것.
			: 상호 조인의 결과의 전체 행 갯수 == 두 테이블의 각 행 갯수를 곱한 숫자. 
				ex ) A 테이블의 행이 3,  B 테이블의 행이 4 이면 결과는 12 행
SELECT *
FROM <첫 번째 테이블>
    CROSS JOIN <두 번째 테이블>

		(4) SELF JOIN 자체 조인: 자신이 자신과 조인하는 것. 1개의 테이블만 사용된다.
SELECT <열 목록>
FROM <테이블> 별칭A
    INNER JOIN <테이블> 별칭B
[WHERE 검색 조건]
