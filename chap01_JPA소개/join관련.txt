테이블 join : 두 개의 테이블을 엮어 하나의 결과를 추출할 때 사용
	: https://velog.io/@newdana01/Database-%ED%85%8C%EC%9D%B4%EB%B8%94-%EC%A1%B0%EC%9D%B8-%EC%9D%B4%ED%95%B4%ED%95%98%EA%B8%B0
	: PK 와 FK 관계로 맺어져야됨 ( 일대다 관계 )
	: 쿼리문 tip  >> 
		: 테이블조인에 대한 조건은 "on" << 그러니까 어떤 기준으로 테이블 묶을 건지.
		: 데이터필터링에 대한 조건은 "where" << 그러니까 어떤 데이터만 표시할지.

	: 종류
		(1) INNER JOIN 내부 조인: 교집합 데이터를 기준으로 결합하여 조회하는 방법.
			: 가장 보편적인 조인. 그냥 조인이라고 함 inner join 이다.
			: 두 테이블에 모두 데이터가 있어야 결과가 나온다.
SELECT <열 목록>
FROM <첫 번째 테이블>
    INNER JOIN <두 번째 테이블>
    ON <조인 조건>
[WHERE 검색 조건]

		(2) OUTER JOIN 외부 조인: 공통데이터 뿐 아니라 한쪽에만 존재하는 데이터까지도 함께 결합하여 조회하고자 할 때 사용하는 방법
			: 순서에 따른 영향을 받는다. 어떤 테이블을 먼저 접근하냐 따라 쿼리 성능에 영향을 미친다.
			: OUTER JOIN의 종류 : 데이터가 한 쪽에만 존재할 때, 어느 테이블을 기준으로 삼을 것인가
				1. LEFT OUTER JOIN : 왼쪽 테이블의 모든 값이 출력되는. 그러니까 오른쪽 테이블에 없는 데이터를 가진 열이라도,  출력된다.
				2. RIGHT OUTER JOIN : 오른쪽 테이블의 모든 값이 출력되는.
				3. FULL OUTER JOIN : 왼 오 테이블의 모든 값이 출력되는
SELECT <열 목록>
FROM <첫 번째 테이블(LEFT 테이블)>
    <LEFT | RIGHT | FULL> OUTER JOIN <두 번째 테이블(RIGHT 테이블)>
     ON <조인 조건>
[WHERE 검색 조건]

		(3) CROSS JOIN 상호 조인 : 한쪽 테이블의 모든 행과 다른 테이블의 모든 행을 조인하는 것.
			: 상호 조인의 결과의 전체 행 갯수 == 두 테이블의 각 행 갯수를 곱한 숫자. 
				ex ) A 테이블의 행이 3,  B 테이블의 행이 4 이면 결과는 12 행
SELECT *
FROM <첫 번째 테이블>
    CROSS JOIN <두 번째 테이블>

		(4) SELF JOIN 자체 조인: 자신이 자신과 조인하는 것. 1개의 테이블만 사용된다.
SELECT <열 목록>
FROM <테이블> 별칭A
    INNER JOIN <테이블> 별칭B
[WHERE 검색 조건]
