	: Iterator객체를 관리하는 인터페이스
		: Iterable 의 존재 이유 >> iterator( ) 매서드를 하위 클래스들이 무조건 가지게 하여 , 그 하위 클래스들의 객체들을 모두 iterator 객체화 할 수 있게 하기 위함

	: 메서드
		default void forEach(Consumer<? super T> action ) :

Iterator 인터페이스
	: 모든 컬렉션 프레임워크에 공통으로 적용 가능한 메서드들을 보유하고 있는 인터페이스
		: Collection 과 딱히 상속 관계 없지만, 컬렉션 객체들은 모두 .iterator( ) 를 통해 Iterator 객체화가 가능하기 떄문에 가능

	: 주로 컬렉션 프레임워크를 표준화된 방법으로 읽기 위해(순회위해) 사용

	: Iterator객체 생성 방법
		Iterator<T> 변수명 = 컬렉션객체명.iterator( );

	: Iterator 객체를 대상으로 사용하는 메서드
		boolean hasNext( ) : Iterator 에 다음 값이 들어있는지 확인
		Object next( ): Iterator 에서 다음값 가져옴 
		void remove( ): next( ) 로 읽어온 값을 컬렉션 상에서 삭제
			; 주의  ) next( ) 를 실제로 호출한 뒤 바로 뒤에서 remove( ) 해야 반영된다
		
	: 주의(단점)
		0. 한번 사용된 Iterator 객체는 재사용 불가. (한번 next( ) 로 모든 요소를 다 읽으면 그다음엔 더 읽을게 없어짐)
		1. 처음부터 끝까지의 단방향 반복만 가능
		2. 대상 "컬렉션 객체" 상의 값의 제거는 가능하나 추가가 불가

Collection 인터페이스
	: (List 와 Set의 ) 실질적인 최상위 인터페이스 (다형성 구현)
	: 메서드
		: get 기능은 Collection 인텊페이스에 구현되어있지 않다. (각 컬렉션마다 자료구조가 제각각)
		boolean add(Object o) : 객체를 해당 컬렉션의 요소로 추가
		boolean addAll(Collection c) : 다른 컬렉션의 모든 요소들을 해당 컬렉션의 요소로 추가

		boolean contains(Object o) : 해당 객체를 포함하고 있나 확인
		boolean isEmpty( ) : 해당 컬렉션이 비어있는지 확인
		int size( ) : 컬렉션에 저장된 요소 수 반환

		boolean remove(Object o ) : 해당 객체를 컬렉션에서 삭제
		boolean removeAll(Collection c ) : 다른 컬렉션에 포함된 모든 요소를 해당 컬렉션에서 삭제
		void clear()	: 해당 컬렉션에서 모든 요소 삭제

		Iterator iterator( ) : 해당 컬렉션 객체를 iterator 객체로 반환 


List 인터페이스 :  순서가 있고 중복을 허용하는 데이터 집합.
	: 메서드
		void add(Object elmt ) : 제일 끝에 요소 "삽입"
		void add(index , Object elmt ) : 해당 인덱스에 요소 "삽입"
		Object set(int index , Object elmt) : 해당 인덱스를 해당 요소로 "변경"  
		Object get( int index ) : 해당 인덱스의 요소 반환
		Object remove(int index) :해당 인덱스의 요소 삭제 및 삭제된 객체 반환

		int indexOf( Object o ) : 해당 객체의 인덱스 반환


ArrayList 클래스: 배열 처럼 index 기반 접근 but 사이즈가 동적이라 맘껏 추가 가능한 자료구조
	: https://inpa.tistory.com/entry/JAVA-%E2%98%95-ArrayList-%EA%B5%AC%EC%A1%B0-%EC%82%AC%EC%9A%A9%EB%B2%95#arraylist_%EC%9D%B4%ED%84%B0%EB%A0%88%EC%9D%B4%ED%84%B0
	: 주의 >> ArrayList 특성상 데이터가 연속으로 저장되어야한다. (띄엄띄엄 x)
		: void add(index , Object elmt ) 에서 index <= 현재 가장 마지막 요소의 바로 다음 인덱스 여야된다. 안그럼 예외 발생한다.
  
	: ArrayList 객체 생성 방법
		: 여기서 E == 저장될 요소들의 자료형
		1. new ArrayList<E>( ) : 사이즈가 10인 ArrayList 생성
		2. new ArrayList<E>(int capacity) : 사이즈가 capacity 인 ArrayList 생성
		3. new ArrayList<E>(Collection c ) : 다른 컬렉션 객체의 요소를 요소로 가지는 ArrayList 생성

	: 요소 삽입 방법
		1. void add(Object elmt )
		2. void add(index , Object elmt ) 

	: 요소의 변경 방법
		1. Object set(int index, Object o) : 해당 인덱스의 요소를 해당 객체로 변경

	: 요소의 삭제 방법 
		: 중간 요소 삭제시 뒷 요소들이 당겨진다
		1. Object remove(int index) : 해당 인덱스에 있는 객체를 제거한다.
		2. boolean remove(Object o) :해당 객체를 제거한다 (성공시 true 반환)
		3. void clear( ) : ArrayList 의 모든 요소 삭제

	: 요소 get 방법 >> Object get(int index) : 해당 위치의 객체 get

	: 상태 파악 방법
		1. boolean isEmpty( ) : 비어있나
		2. boolean contains(Object o ): 해당 객체를 포함하나
		3. int indexOf( Object o ) :해당 객체의 저장 인덱스  
		4. int size( ) : 사이즈 반환

	: 배열화 >> Object[ ] toArray( ) 

	: 깊은 복사 >> Object clone( ) 
		: 주의 )  ArrayList는 내부적으로 Object[] 배열로 저장하기 때문에 형변환이 필요함
		: ex ) 
			ArrayList<Integer> number = new ArrayList<>();
			number.add(1); number.add(3); number.add(5);
			ArrayList<Integer> cloneNumber = (ArrayList<Integer>) number.clone();
	
	: ArrayList 이터레이터
		Iterator iterator( ) : ArrayList 의 이터레이터 객체 반환 >> .hasNext( ) , .next( ) 같은거 사용 가능
		ListIterator listIterator( ) : ArrayList 의 ListIterator 객체 반환

		
컬렉션 프레임워크
	: (다수의 데이터를 효과적으로 처리할 수 있게) 자료구조를 구현한 클래스 집합
	: 주의 >> 저장할 수 있는 데이터는 오로지 객체뿐 ( primitve 불가 )
	: 컬렉션 프레임워크 유형
		(1) Iterable 인터페이스 
			▼Collection 인터페이스
				▼List 인터페이스 : 순서가 있고 중복을 허용하는 데이터 집합.
					▶ Vector 구현 클래스 : 요즘엔 잘 안쓴다
					▶ ArrayList 구현 클래스

				▼Set 인터페이스 : (순서가 없고) 중복을 허용하지 않는 데이터 집합
					▶ HashSet 구현 클래스

		(2)Map 인터페이스 : (순서가 없고) 키와 값의 쌍으로 이루어진 데이터 집합
			▶ HashMap 구현 클래스
