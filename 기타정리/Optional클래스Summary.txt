    : java.util.Optional
								:  'null일 수도 있는 객체'를 감싸는 일종의 Wrapper 클래스
									: null 값이 할당된 객체를 참조하더라도 에러가 나지 않도록 해준다 (NPE Null Pointer Exception 방지)
									: 명시적으로 해당 변수가 null일 수도 있다는 가능성을 표현할 수 있다
									: null 일 수도 있는 객체를 다룰 수 있는 API 여러 API 제공한다
									: wrapper class
										: A type 의 데이터를 B type객체로 포장해주는 클래스
										: java.lang.XXX										
										: 산술 연산을 위한 클래스는 아니라 인스턴스에 저장된 값을 변경할 수 없고, 단순 생성 및 참조만 가능
										: Boxing 과 Unboxing
											: Boxing >> primive type 데이터를 wrapper 클래스의 인스턴스로 변환하는 과정
											: Unboxing >> wrapper 클래스의 인스턴스에서 primive type 데이터를 꺼내는 과정

											: AutoBoxing과 AutoUnBoxing
												: 자동형변환. Wrapper 타입 변수에 primivite 값 할당하면 new 연산자를 쓰지 않아도 해당 값을 기반으로 wrapper 클래스 인스턴스가 생성되고, primitive 타입 변수에 wrapper 클래스 객체를 할당하면 자동ㅇ로  값이 꺼내진다.

												: ex )

									3. Optional 객체 접근 >>Optional이 담고 있는 객체가 존재할 경우 모두 동일하게 그 객체를 반환하지만, Optional이 비어있는 경우(null) 다르게 작동
										: 죄다  인스턴스 대상으로 쓰이는 매서드
										(1) get( )  : 비어있는 Optional 객체를 대상으로  접근시 예외 발생시킴
