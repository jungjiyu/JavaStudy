tip >> 뷰텝플릿엔진 쪽이 좀 특이한거지 , 일반적으론 다 "/" 명시해서 쓴다. 
	1. @RequestMapping >> "/경로"
	2. form 태그에서 action 경로 >> "/경로"
	3. html 에서 외부 파일(css , js ) 링크할 때 경로 >> "/경로"
		: static 디렉터리를 기준으로 내부 파일의 경로를 / 와 확장자를 명시하여 할당한다

	4. redirect 경로 >> "redirect:/경로"

	3. return 뷰네임 >> "확장자제외한뷰템플릿명"
		: 디렉터리내부의 파일에 접근할떄도 '/' 과 확장자는 명시하지 않는다 ( "디렉터리/확장자제외한뷰네임명" )

	4. mustache 에서 다른 mustache파일 inlude 할때의 경로 >> template디렉터리기준상대경로
		: 같은 레벨에 있건 상위/하위 레벨에 있건 무조건 tempalte디렉터리를 기준으로 한 상대경로로 작성한다. 확장자는 제외한다.
		ex ) 아래의 상황에서 form1.mustache 내부에서 header.mustache 를 inlcude 하고자 한다면 {{>layouts/header}} , form3.mustache 를 inlcude 하고자 한다면 {{>forms/priavteforms/form3}} 를 사용한다 
			▼template
				▼forms
					▶form1.mustache
					▶form2.mustache
					▼privateforms
						▶form3.mustache

				▼layouts
					▶header.mustache
