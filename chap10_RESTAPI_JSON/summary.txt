: REST REpresentational State Transfer >>  자원을 이름으로 구분하여 해당 자원의 상태를 주고받는 모든 것
	: 자원을 이름(URI)로 구분하여 HTTP Method(POST, GET, PUT, DELETE)를 통해 해당 자원에 대한 CRUD Operation을 적용하는 것
	: representational == 표현적인.  
	: state == 상태
	: transfer == 전송


REST API 
	: REST 기반 API
	: 서버의 자원을 클라이언트에 구애받지 않고 사용할 수 있게하는 설계 방식.
		: 클라이언트는 웹 브라우저만 있는게 아니라 스마트폰 , 스마트워치 ... 등 다양하고, 서버는 이러한 다양한 클라이언트로부터의 요청에 응답해야한다. 

	: HTTP request 대한 response 로 "특정기기에 종속되지 않는 서버의 자원"을 반환한다.
		: view 가 아닌 data 를 response 하고, 이때 응답되는 데이터가 JSON , XML 이다
			: (사람과 기계 모두 이해하기 쉬우며 용량이 작아서) 요즘엔 JSON 으로 통일되는 추세

	: 모든 HTTP 메서드를 지원한다.
		1. Create --> post 
		2. Read --> get
		3. Update --> put 혹은 patch
			: put >> 전체 변경
			: patch >> 부분 변경
		4. Delete --> delete



	: JSON 기반 REST API 연습 사이트 >> place holder ( https://jsonplaceholder.typicode.com/ )
		: 가짜 API 이다
		: Routes
			모든 게시글 조회>> 	/posts  
			1번 게시글 조회 >>	/posts/1
			1번 개시글의 모든 댓글 조회 방법1 >>	/posts/1/comments
			1번 개시글의 모든 댓글 조회 방법2>>	/comments?postId=1
			게시글 생성 >>	/posts
			1번 게시글 수정 >> 	/posts/1
			1번 게시글 수정 >>	/posts/1
			1번 게시글 삭제 >>	/posts/1

JSON JavaScript Object Notation >> 데이터의 교환/저장을 쉽게 해주는 텍스트 기반의 데이터 교환 표준.(표현법)
	: 직역하면 자바 스크립트 객체 표기법
		: Notation == 표기법
		: Javascript에서 객체를 만들 때 사용하는 표현식을 사용한다
	
	: 문법		
		: object >> key 와 value 로 구성된 정렬되지 않은 property( 속성 ) 의 집합
			: 객체 생성 형식 >> javascript 랑 표현 방식이 같다
				{
					"키명1" : 값1,
					"키명2" : 값2 ,
					. . . 
					"키명n" : 값n
				}

				: key>> 문자열이라 항상 " " 로 표기한다.
				: value >> 문자열일 수도 있고 숫자일수도 있으므로 알잘딱깔센
				: key 와 vlaue 는 ':' 로 바인딩하고, 여러 데이터를 나열할 경우 ',' 를 사용한다
				: 최종적으론 중괄호 로 묶는다.

			: 객체는 다른 객체의 property 값일 수 있다
				ex ) 	{"판매자정보" : { "이름" : "남도일", "지역" : "서울" } , "판매품목" : ['사과','배','딸기']  }

			: 활용 형식
				sol1. 배열적 표현 >> 객체명[ "속성명" ]
				sol2. 객체적 표현 >> 객체명.속성명



		: 배열 array
			: 형식 >>  [ 값1 , 값2 , 값3 .. ] 
				: 대괄호로 감싼다
				: ex ) var Characters = [
    					{ '이름' : '남도일',  '성별' : '남',   '나이' : 18 },
    					{ '이름' : '유미란',  '성별' : '여', '나이' : 17 } ]

			: 요소 추가 방법 >> 배열명.push( 값 )
				ex ) var Character = { '이름' : '장미란',  '성별' : '남',   '나이' : 40 },
				     Characters.push(Character);
	 
			: 객체를 요소로 할 때 , 각 객체마다 속성 추가 방법
				sol1. 배열명.새항목명 = 값;
					ex ) Character.성인여부 = true;

				sol2. 배열명["새항목명"] = 값;
					ex ) Character["성인여부"] = true;
					ex ) var key ="성인여부";
						Character[key] = true;

			: 객체를 요소로 할 때 , 각 객체의 속성 삭제 방법 >> delete 배열명.속성명
				ex ) delete Character.직접잡은범인
			
		: value 의 타입
			1. 숫자 number  --> 쌩 숫자
			2. 문자열 string --> "쏼라쏼라" 혹은 '쏼라쏼라'
			3. 불리언 boolean ---> true , false 
			4. 객체 object
			5. 배열 array 
			6. null	


		: 제공 메서드 
			1. JSON.stringfy ( 변수 ) >> 객체를 문자열로 변환해준다
				ex )	 var str = {"test" : "value"}
					var parsingData = JSON.parse(str); //  '{ "test" : "value" }' 

			2. JSON.parse( 변수 ) >> 문자열을 객체로 변환해준다
				ex )	 var str = '{ "test" : "value" }';
					var parsingData = JSON.parse(str); // {"test" : "value"}
