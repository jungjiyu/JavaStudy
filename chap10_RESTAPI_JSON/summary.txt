자바스크립트 Promise 개념
	: 비동기 처리 >> 현재 실행중인 작업과 별도로( 병렬적으로 ) 다른 작업을 수행하는 것,
	: 콜백 함수 >> 비동기 작업이 완료되면 호출되는 함수. 비동기 함수의 매개변수로 함수 객체를 넘기는 기법. 
		: 중첩되면 개복잡 해진다. 콜백 지옥.

		function increaseAndPrint(n, callback) {
		  setTimeout(() => {
 		   const increased = n + 1;
  		  console.log(increased);
  		  if (callback) {
  		    callback(increased); // 콜백함수 호출
  		  }
 		 }, 1000);
		}

		increaseAndPrint(0, n => {
		  increaseAndPrint(n, n => {
  		  increaseAndPrint(n, n => {
  		    increaseAndPrint(n, n => {
    		    increaseAndPrint(n, n => {
   		       console.log('끝!');
  		      });
 		     });
 		   });
		  });
		});
	
	: Promise 객체 >> 비동기 작업의 최종완료||실패 결과 를 나타내는 객체
		: 비동기 작업의 결과를 반드시 반환하겠단 의미서 Promise 라 이름 지어졌다
		: 콜백 지옥을 벗어나게 해준다
		: 비동기 작업 갯수가 많아져도 코드가 깊어지지 않는다
		: Promise 객체 생성 방법 
			const myPromise = new Promise((resolve, reject) => {
				const data = fetch('요청할URL');

   				 if(data) resolve(data); // 요청 성공하여 데이터가 있다면
 				 else reject("Error");
			})

				: arg 로 들어가는 콜백함수의 0번째 인수는 성공(resolve) 를 나타내는 객체, 1번째 인수는 실패(reject) 를 알려주는 객체.
					: Promise 생성자 안에 들어가는 콜백함수를 executor 라고 부른다
				: fetch 의 결과로 데이터가 있다면 if 문이 실행되어 resolve 함수가, 그렇지 않다면 reject 함수가 실행된다. 이때 resolve 함수의 경우 arg 로 data, 즉 fetch( ) 의 결과를 넣어준다

		
		: Promise 객체 처리 방법 
			: 생성된 Promise 객체를 이용하여 비동기 작업 완료 이후에 다음 작업을 연결시켜, 체인처럼 , 진행할 수 있다
				: 줄줄이 이어 쓰는걸 체이닝이라고 한다
			: 프로미스 핸들러  << promise 객체 활용하는 메서드들 
				then( (value) => { 실행내용 .. } )  --> 비동기작업성공했을 경우 실행되고, 새로운 Promise 객체를 반환한다
					: resolve 에서 fetch( ) 의 결괏값을 arg로 주기 떄문에 then 내부의 함수 객체에서 해당 결괏값을 활용 가능하다 ( then 내부서 받은 파라미터 변수명으로 )
				catch( ( error ) => { 실행내용 .. } ) --> 비동기 작업 실패했을경우 실행되고, 새로운 Promise 객체를 반환한다

				
				fianlly( ( ) => { 실행내용 }  ) --> 무조건 실행시키고, 새로운 Promise 객체를 반환한다.

		: promise 객체 state  ) Pending - Fulfilled - Ejected 
			Pending >> 대기 상태. 처리가 완료되지 않은, 진행중인 상태
			Fullfilled >> 성공적으로 처리가 완료된 상태
			Ejected >> 처리가 실패적으로 끝난 상태

		: promise 객체는 보통 코드 자체에서 직접 생성 안하고, 함수를 만들고 반환하게 하여 사용하는 편이다
			: 결국 " 함수명( ).then( 어쩌구 ).then( 어쩌구 ) ... " 이런식으로 쓰게 되는거다
			: 프로미스 객체를 생성하여 반환하는 이러한 함수를 "프로미스 팩토리 함수" 라고 부른다
			: 대표적으로 fetch( ) 함수가 "프로미스 팩토리 함수" 이다
				fetch( "요청경로" ) // response 객체 반환 
 				.then((response) => response.json()) // response 객체 받고 JSON 데이터 반환
  				.then((data) => console.log(data)); // 받은 JSON 데이터를 출력

		: 여러개의 비동기 처리를 한번에 하는 법 >>
			: 공통적으로 fetch( ) 를 요소로 하는 배열을 Promies.all(  )메서드의 arg 로 한다

			1.  Promise.all( [ fetch( "경로1 " ) ,fetch( "경로2 " ) , ... ]  ) 
				: all( ) 내부의 "모든" 비동기 처리가 완료되어야 이 뒤의 then( ), catch( )로 넘어간다.

			2. Promise.any(  [ fetch( "경로1 " ) ,fetch( "경로2 " ) , ... ]  ) 
				: all( ) 내부의  비동기 처리 중 하나라도 "성공적으로" 완료되면 바로 뒤의 then( ), catch( )로 넘어간다.
					: 그러니까 아무리 처음에 반환된 결과라도 그게 실패이면 무시되는거다
					: 모두 성공적이지 않을 시 최종적으론 실패 결과를 반환
		
			3. Promise.race(  [ fetch( "경로1 " ) ,fetch( "경로2 " ) , ... ]  ) 
				: 비동기 처리중 젤 먼저 완료된 것을 반환하고, 다음 then( ) , catch( ) 로 간다	
				: any 와 다르게 성공 실패 여부가 중요하지 않다

REST API 
	: REST 기반 API
	: 서버의 자원을 클라이언트에 구애받지 않고 사용할 수 있게하는 설계 방식.
		: 클라이언트는 웹 브라우저만 있는게 아니라 스마트폰 , 스마트워치 ... 등 다양하고, 서버는 이러한 다양한 클라이언트로부터의 요청에 응답해야한다. 

	: HTTP request 대한 response 로 "특정기기에 종속되지 않는 서버의 자원"을 반환한다.
		: view 가 아닌 data 를 response 하고, 이때 응답되는 데이터가 JSON , XML 이다
			: (사람과 기계 모두 이해하기 쉬우며 용량이 작아서) 요즘엔 JSON 으로 통일되는 추세

	: 모든 HTTP 메서드를 지원한다.
		: 기본 형태
			(1) fetch('요청URL', 옵션객체)
				: fetch >> HTTP request 전송 기능을 제공하는 클라이언트 사이드 web API . 즉 , 서버와의 통신을 통해 CRUD 를 구현할 수 있게 하는 함수
				: 브라우저에 내장되어있다.
				: 파라미터 
					: ' 경로 ' >> HTTP request 할 URL
					: 옵션객체 >> { method , headers, body } 
						: 필요 없으면 생략 가능
						: 주의 ) 요청 코드 자체는 json 이 아니라 자바스크립트이므로 자바스크립트의 표현법을 따른다. 따라서 객체의 속성은 문자열( 이건 JSON 의 객체에서 key 표현법 )이 아닌 걍글자(?) 로 표현한다.
						: method >> HTTP 요청 메서드
							: 'HTTP 요청 메서드' 를 할당
							ex) method='post'

						: headers >> HTTP 헤더 
							: "Content-Type": "application/json" 
								:JSON 형식으로 데이터를 보내달란 뜻

						: body >> payload 작성
							:  아래에서 "data" 가 실질적인 데이터 즉 payload
 							{ "status" : "OK"
  							"from": "localhost",
  							"to": "https://hanamon.kr/users/1",
  							"method": "GET",
 							 "data":{ "username" : "하나몬" }
							}

				: 반환 >> HTTP 응답을 나타내는 response 객체를 wrapping 한 객체 반환
					: Response 객체 >> HTTP response status/header/body 등을 읽어올 수 있다	
					: Response.ok == HTTP 응답 성공 여부를 나타내는 속성
						true = 200 (응답 성공)
						false = not (응답 실패)
				
					: Response.status = 서버가 어떻게 response 했는지 알려줌
						상태코드 클래스
							1XX >> Informational ( 처리중 )
							2XX	>> SUCCESS (정상처리)
							3XX >> Redirection (추가 request 필요)
							4XX >> Clinet Error ( 잘못된 request )
							5XX >> Server Error (서버측에서 처리하다 에러남)			
					: Response.prototype
						: Response 객체의 활용 위한 다양한 메서드 제공
						: Response.prototype.json 메서드 >> Response 객체에서 HTTP BODY ( response.body) 를 취득해 역직렬화 ( JSON 포맷 문자열을 객체화 )

			(2) .then( (response) => response.json( ) ) 
				: response는 HTTP 응답을 나타내는 Response 객체.
				: json( ) 메서드를 활용해 역직렬화 한다

			(3) .then((json) => console.log(json)) 
				: json 은 역직렬화된 HTTP response Body

		: REST API 의 구성 3요소

			(3) representation : 자원에 대한 행위의 구체적 표현.내용  --> payload 로 표현
